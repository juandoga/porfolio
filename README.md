# Juan Domenech — Fotografía

Porfolio fotográfico. Web estática (HTML, CSS y JavaScript, sin dependencias externas).

- `index.html`: la página.
- `data.js`: nombre, contacto, series, textos, orden, portadas y lugares de cada foto.
- `img/` y `thumb/`: fotografías a tamaño web y miniaturas.
- `fonts/`: tipografías Archivo y Archivo Black (licencia SIL Open Font License).
- `og.jpg`: imagen que aparece al compartir el enlace en redes.
