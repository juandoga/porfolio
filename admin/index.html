Gestión del porfolio

Esta página solo funciona con una llave tuya de GitHub. Se guarda en este navegador y no se envía a ningún otro sitio. Hay que hacerlo una vez por navegador.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: «porfolio». Caducidad: la que quieras (por ejemplo, 1 año).
  3. En Repository access elige Only select repositories y marca porfolio.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Pulsa Generate token, copia la llave y pégala aquí.
